# Sputnik — диктофон с заметками

Приложение для Android на Python/Kivy: голосовые записи с текстовыми заметками, воспроизведением, поиском и отправкой через системное меню.

## Возможности

- Запись голоса (MediaRecorder, AAC в контейнере MPEG-4) с таймером на экране.
- Сохранение в общедоступную папку Music/Sputnik через MediaStore (API 29+) или прямое копирование на старых версиях.
- Частная резервная копия каждой записи внутри приложения (суффикс `_p`).
- Заметки к записям с переносом строк и автоувеличением карточек.
- Поиск по тексту заметок.
- Воспроизведение с прогрессом и счётчиком «позиция / длительность».
- Удаление с защитой от случайного нажатия: кнопка на 3 секунды превращается в «ТОЧНО?».
- Отправка записи через системное меню (ACTION_SEND).

## Состав проекта

- `main.py` — всё приложение в одном файле.
- `fonts/Montserrat-Regular.ttf`, `fonts/Montserrat-Bold.ttf` — шрифты.

## Как устроено сохранение

1. Запись сначала идёт во временный файл `rec_tmp.m4a` внутри приложения.
2. По остановке файл переименовывается в `rec_ГГГГММДД_ЧЧММСС_p.m4a` — это частная резервная копия, источник истины.
3. На Android 10+ содержимое дублируется в MediaStore (запись создаётся с флагом `is_pending`, после записи флаг снимается).

## Выученные уроки (важно для будущих правок)

- Колонки MediaStore называются с подчёркиванием: `_display_name`, `_size`. Без него — `IllegalArgumentException: Invalid column`.
- Uri из MediaStore не хранит смысл надолго: на Android 15 после снятия `is_pending` строка пересоздаётся, старый uri умирает («No content provider»). Поэтому отправка всегда создаёт себе свежую запись из частной копии и проверяет её обратным чтением.
- Отправляемый тип: `audio/mp4`. Тип `audio/*` сужает список приложений-получателей.
- Меню отправки использует `createChooser`; EXTRA_TITLE даёт нормальное имя файла в шапке меню даже там, где прошивка не отдаёт метаданные.

## Диагностика в статусе

- «Записано: файл N б, uri N б, Android 35» — сравнение размера частной копии и записи MediaStore сразу после сохранения.
- «Отправка [mp4]: файл N б, uri N б (свежая запись)» — проверка перед меню; числа должны совпадать.
- «Сохранено только внутри приложения: …» — MediaStore не принял запись, текст ошибки приложен.

## Сборка

1. Commit changes.
2. Дождаться зелёной сборки, скачать артефакт из **нового** запуска.
3. Старое приложение удалить, новый APK установить (версия фиксирована `1.0` — Android не отличит сборки сам).

## Известные ограничения

- Алиса не появляется в списке получателей для аудиофайлов — она не декларирует приём аудио; это решается вне приложения (MAX, почта, Диск).
- «−1 б» в статусе после отправки — косметика, файл доходит целым (подтверждено получателями).
- Водяной знак «SPUTNIK» на фоне — элемент защиты от заимствования, по задумке проекта.

Это тот самый паспорт проекта — теперь вы можете проверить, что файл в репозитории совпадает с ним, и при желании что-то подправить. Готов двигаться дальше — скажите, что берём: версия 1.1, редактирование заметок или экспорт списка одним файлом.
